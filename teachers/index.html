🖨️ Print a worksheet with an answer key
  1. Unlock this device with the teacher code (above).
  2. Open a course and go to a unit's Practice section, then the 🖨️ Worksheet tab.
  3. Pick the lessons, number of questions, level (Base Camp, Climb or Summit) and version.
  4. Make sure Answer key is checked. It prints on its own page after the questions.
  5. Versions A–D always come out the same, so you can reprint them. Give neighbours different versions, or choose "New mix" for a fresh set.

Levels are remembered on each device, so a student's Chromebook can stay on Base Camp.

⛰️ Open the next unit

The easiest way: ask Claude to "open Unit 6 of Grade 9 Math and make it the current unit."

To do it yourself: open the course folder on GitHub, edit index.html, and near the bottom (under "EDIT HERE: the unit list") change that unit's open: false to open: true and set current to the unit number. Note that the next time Claude rebuilds the pages, its own unit list is used, so let Claude know about changes you make by hand.

🏔️ Award or remove AvCash
  1. Open the Avalanche HQ teacher app (Quick links).
  2. Pick the student, then tap 1, 2, 5 or 10.
  3. To take AvCash away, tap +/− first. It switches back to adding after each award.
🛒 Change store items or prices

Store items live in the Google Sheet, on the Items tab. Edit a row (name, emoji, price) and the store updates. There's no need to change the website.

🔊 Use read-aloud and larger text with the class

On any course page, tap the round buttons in the bottom-right corner. With read-aloud on, 🔊 buttons appear beside big ideas, examples, questions and flashcards. The voice comes from each device, so it sounds different on a Chromebook, an iPad or a phone.

🔒 Change or reset the teacher code

Ask Claude to change the teacher code. Devices that were unlocked with the old code will need the new one. Use Lock this device (above) on any shared or student device after previewing.

4Substitute teacher quick start

👋 Welcome

  • This is a combined Grade 8/9 class. Grades often work on similar topics side by side.
  • Your plan for the day is in the sub plans folder (Quick links) or on the desk.
  • Students know the site well. Ask a Grade 9 student to show you around a course page.

🧭 When students finish early

  • Open the current unit (Course status above) and go to Practice.
  • Students choose a 🎯 Practice set at their level, or the unit's 🃏 Flashcards.
  • Students can also work on an Expedition from the current lesson.

🏔️ Avalanche HQ

  • Students earn AvCash for effort, teamwork and kindness.
  • If you've been given access, award it in the teacher app (Quick links). Small amounts (1–2) are typical.
  • No access? Jot names and reasons on the sub notes, and the classroom teacher will award it later.

📝 Before you leave

  • Leave notes on what was finished and anything that came up.
  • If you used preview links on a classroom computer, tap Lock this device.
